## 💡 Чему мы научились

### 1. Flutter API события указателя
**Учение:** `PointerMoveEvent` содержит `position`, а не `localPosition`

**Применение:** Используем `RenderBox.globalToLocal()` для преобразования координат

**Практика:** Это принцип работает для всех событий указателя в Flutter

### 2. Преобразование координат в Flutter
**Учение:** Всегда конвертируйте глобальные координаты в локальные

**Практика:** Шаблон: 
```dart
final renderBox = context.findRenderObject() as RenderBox?;
if (renderBox != null) {
  final localPos = renderBox.globalToLocal(globalPos);
}
```

### 3. Тестирование сложных виджетов
**Учение:** Нужны достаточно большие контейнеры для отрисовки

**Практика:** Используйте 300x300 для тестирования вместо 100x100
