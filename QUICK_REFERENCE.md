# Fly Mixxx - Quick Reference Guide

## Getting Started

### First Launch
1. Open Fly Mixxx application
2. Grant storage permissions (Android)
3. Navigate to your music folder
4. Load tracks on Deck 1 and Deck 2

### Basic Mixing (5 Steps)

1. **Load Tracks**
   - Click on Deck 1, select first track
   - Click on Deck 2, select second track

2. **Match Tempo**
   - Note BPM of both tracks
   - Adjust Deck 2 tempo to match Deck 1
   - Listen for beat alignment

3. **Set Volumes**
   - Adjust Deck 1 volume to desired level
   - Adjust Deck 2 volume to match
   - Set Master Volume to 80-90%

4. **Start Playback**
   - Click Play on Deck 1
   - Let it play for 8-16 bars
   - Click Play on Deck 2

5. **Transition**
   - Move Crossfader from left to right
   - Adjust EQ if needed
   - Complete transition over 8-16 bars

| Control | Function | Range |
|---------|----------|-------|
| Play/Pause | Start/stop playback | - |

## Common Tasks

### Load a Track
1. Click on deck
2. Browse to music file
3. Select and confirm
4. Track loads automatically

### Seek to Position
1. Click on progress bar
2. Drag to desired position
3. Release to seek

### Adjust Equalizer
1. Click and drag slider up (boost) or down (cut)
2. Adjust multiple bands for desired sound
3. Click "Reset" to return to flat

### Match Tempo
1. Note BPM of Deck 1 track
2. Adjust Deck 2 BPM slider to match
3. Fine-tune with Tempo slider
4. Listen for beat alignment

### Smooth Transition
1. Set Crossfader to Deck 1 (left)
2. Play Deck 1 for 8-16 bars
3. Start Deck 2 playback
4. Gradually move Crossfader to center
5. Continue to Deck 2 (right)

## Tips & Tricks

### For Better Sound
- Use high-quality audio files (320kbps+)
- Adjust EQ for your speakers/headphones
- Keep master volume at 80-90%
- Use external audio interface if available

### For Smooth Mixing
- Match BPM before transitioning
- Use crossfader gradually (8-16 bars)
- Adjust EQ during transitions
- Practice beat matching

### For Tango Music
- Use Classic Tango preset for traditional sound
- Boost bass (60Hz) for rhythm
- Enhance bandoneon (150Hz-1kHz)
- Emphasize strings (2.4kHz-6kHz)

### For Longer Sets
- Prepare playlist in advance
- Pre-cue next track while current plays
- Use consistent BPM throughout
- Take breaks between sets

## Troubleshooting Quick Fixes

| Problem | Quick Fix |
|---------|-----------|
| No sound | Check device volume, verify file format |
| Tempo mismatch | Use tempo slider to fine-tune |
| Muddy sound | Reduce overlapping frequencies with EQ |
| Distortion | Lower master volume |
| App crash | Restart app, check file integrity |
| Slow performance | Close other apps, free up storage |

## Recommended Settings

### For Beginners
- BPM: 120 (standard)
- Tempo: 1.0x (normal)
- Master Volume: 80%
- Crossfader: Use gradually

### For Experienced DJs
- BPM: 60-240 (flexible)
- Tempo: 0.5x-2.0x (creative)
- Master Volume: 85-95%
- Crossfader: Use creatively

### For Tango Mixing
- BPM: 100-150 (genre appropriate)
- Tempo: 0.8x-1.1x (smooth)
- Master Volume: 85%
- EQ: Use presets
