# 🎵 Fly Mixxx - DJ Mixer с AI Composition Generator

## Что это?

**Fly Mixxx** - это профессиональное приложение для DJing на Windows с современными функциями:
- 🎚️ Двуканальный DJ-микшер
- 🎛️ 10-полосный эквалайзер с предустановками
- 📊 Анализ частотной характеристики
- 🎵 Загрузка треков с поддержкой папок (до 4 треков на дек)
- 📱 Анализ звукового оборудования
- 🤖 Генерация музыкальных композиций с AI

## 🎯 Основные функции

### 1. DJ Микшер
- Два независимых плеера (Deck 1 & Deck 2)
- Кроссфейдер для плавного переходу между деками
- Управление громкостью каждого дека
- Позиционирование в треке
- Индикатор времени проигрывания

### 2. Эквалайзер
- 10-полосный параметрический EQ
- Предустановки для разных жанров (Tango, Jazz, Folk и т.д.)
- Визуальное отображение текущих настроек
- Сохранение пользовательских пресетов

### 3. Анализ оборудования
```
Что видите:
├── Список аудио-устройств
│   ├── Имя и тип устройства
│   ├── Количество каналов
│   ├── Sample Rate (Hz)
│   ├── Bit Depth (bits)
│   └── Latency (ms)
└── Системная информация
    ├── CPU load (%)
    ├── Memory usage (%)
    └── Buffer size
```

**Как использовать:**
1. Нажмите "Scan" в разделе Audio Device Analysis
2. Просмотрите информацию о устройствах
3. Оптимизируйте параметры при необходимости

### 4. Генератор композиций (AI)
```
Процесс:
1. Загрузите 4 мелодии (Track Loader)
2. Выберите AI провайдер
3. Введите название и тип аранжировки
4. Нажмите "Generate"
5. Экспортируйте результат (MIDI или WAV)
```

**AI Провайдеры:**
- **Local MCP Server** - локально, без интернета ⭐ (рекомендуется)
- OpenAI GPT-4 - облако
- Google MusicLM - облако
- OpenAI Jukebox - облако
- Mubert AI - облако

### 5. Загрузчик треков
- Добавление отдельных файлов
- Добавление целых папок
- Поддерживаемые форматы: MP3, WAV, FLAC, M4A, AAC
- Максимум 4 трека на дек (для AI генерации)

## 🚀 Примеры использования

### Пример 1: Простое миксирование двух треков

1. Загрузите трек 1 в Deck 1 (Track Loader)
2. Загрузите трек 2 в Deck 2
3. Нажмите Play на обоих деках
4. Используйте кроссфейдер для переходов
5. Регулируйте громкость каждого дека

### Пример 2: Создание танго-композиции из 4 мелодий

1. **Подготовка:**
   - Загрузите 4 аудиофайла в формате WAV
   - Убедитесь что это танго-мелодии

2. **Загрузка:**
   - Нажмите "Add Track" 4 раза или "Add Folder" один раз
   - 2 трека в Deck 1, 2 трека в Deck 2

3. **Генерация:**
   - Откройте "AI Composition Generator"
   - Выберите "Local MCP Server"
   - Введите название: "My Tango Mix"
   - Выберите arrangement: "harmony"
   - Нажмите "Generate"

4. **Экспорт:**
   - Дождитесь завершения (обычно 30-60 сек)
   - Нажмите "Export" в формате MIDI или WAV
   - Сохраните файл

### Пример 3: Анализ вашего оборудования

1. Откройте "Audio Device Analysis"
2. Нажмите кнопку "Scan"
3. Посмотрите информацию:
   - Какие устройства подключены
   - Какой sample rate они поддерживают
   - Какая задержка (latency)
   - Какова нагрузка на CPU

4. Оптимизируйте параметры для лучшего звука

## 🆘 Решение проблем

### Проблема: Приложение не запускается

**Решение:**
```bash
flutter clean
flutter pub get
flutter run -d windows
```

### Проблема: Звук не воспроизводится

**Проверьте:**
1. В Audio Device Analysis проверьте что устройство выбрано
2. Проверьте громкость в Windows
3. Убедитесь что формат файла поддерживается (MP3, WAV)
4. Попробуйте другой аудиофайл

### Проблема: Не могу подключиться к MCP серверу

**Решение:**
1. Убедитесь что MCP сервер запущен:
   ```bash
   npm start
   ```
2. Проверьте в браузере: `http://localhost:3000/health`
3. Используйте другой порт если 3000 занят:
   ```bash
   PORT=3001 npm start
   ```

### Проблема: AI генерация не работает

**Проверьте:**
1. Для локального: MCP сервер должен быть запущен
2. Для облачных: нужен интернет и API ключ
3. Должно быть ровно 4 мелодии
4. Попробуйте проверить соединение кнопкой "Test Connection"
