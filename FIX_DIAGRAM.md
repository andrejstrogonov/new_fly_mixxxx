## Поток обработки событий указателя

```
┌─────────────────────────────────────────────────────────────────┐
│                     MOUSE EVENT (Listener)                      │
│                   event.position (глобальная)                   │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   RenderBox.globalToLocal()          │
        │   (преобразование координат)         │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   localPosition (локальная)          │
        │   внутри виджета RotaryKnobWidget   │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   Вычисляем смещение от центра:     │
        │   offset = localPosition - center   │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   Вычисляем угол:                    │
        │   angle = atan2(offset.dy,           │
        │            offset.dx)                │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   Преобразуем в градусы:             │
        │   degrees = angle * 180 / π + 90    │
        │   Диапазон: -135° до +135°          │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   Нормализуем значение:              │
        │   normalized = (degrees + 135) / 270│
        │   Диапазон: [0.0, 1.0]              │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   Преобразуем в диапазон [min, max]:│
        │   value = min + (normalized *        │
        │            (max - min))              │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   Вызываем onChanged callback        │
        │   widget.onChanged(newValue)         │
        └──────────────────┬───────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────┐
        │   UI обновляется автоматически       │
        │   (перерисовка CustomPaint)          │
        └──────────────────────────────────────┘
```

Listener(
  onPointerMove: (event) {
    final renderBox = context
        .findRenderObject() as RenderBox?;
    if (renderBox != null) {
      final localPosition = renderBox
