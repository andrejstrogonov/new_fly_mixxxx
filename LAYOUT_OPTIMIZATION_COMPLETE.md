## 🔧 Технические детали

### Использованные технологии:
- `MediaQuery.of(context).size.width` для определения размера экрана
- Conditional rendering для разных layout-ов
- `Expanded` и `Flexible` для адаптивного распределения пространства

### Breakpoints:
- **Small Screen:** width < 800px (смартфон)
- **Medium Screen:** 800px ≤ width ≤ 1200px (планшет)
- **Large Screen:** width > 1200px (ноутбук)
