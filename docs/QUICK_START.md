# Quick Start Guide - Fly Mixxx DJ Mixer

## ⚡ Быстрый старт

### 1️⃣ Установка и запуск (одна команда)
```bash
cd C:\Users\strog\StudioProjects\new_fly_mixxxx && flutter run -d windows
```

### 2️⃣ Загрузить треки
- **Track Loader** находится в верхней части экрана
- Есть 2 дека (слева и справа)
- Каждый дек может содержать до 4 треков

### 3️⃣ Кнопки загрузки
| Кнопка | Функция | 
|--------|---------|
| **Add Track** | Выбрать один файл MP3/WAV/FLAC/M4A |
| **Add Folder** | Загрузить все файлы из папки |
| **▶** | Воспроизвести трек из очереди |
| **✕** | Удалить трек из очереди |
| **✕ (вверху)** | Очистить всю очередь |

---

## 🎚️ Основные функции

### Управление громкостью
- **Сверху**: Master Volume (общая громкость)
- **На каждом деке**: Volume (громкость дека)

### Кроссфейдер
- Плавный переход между деками
- Находится в центре экрана

### Эквалайзер
- 10-полосный параметрический EQ
- Разные предустановки (Tango, Jazz, Bass Boost и т.д.)

### Визуализация
- Frequency Response (АЧХ) - амплитудно-частотная характеристика
- Phase Response (ФЧХ) - фазо-частотная характеристика

---

## 🎯 Типичный сценарий использования

1. **Подготовка**: Нажмите "Add Folder" на Дек 1
2. **Выберите папку** с музыкой для микширования
3. **Повторите** для Дек 2
4. **Выберите трек** нажав ▶ рядом с названием
5. **Используйте кроссфейдер** для перехода между деками
6. **Регулируйте громкость** для баланса звука

## 🆘 Если что-то не работает

### Ошибка: `file_picker` не найден
```bash
flutter pub get
flutter clean
flutter pub get
```

### Ошибка при запуске на Windows
```bash
flutter config --enable-windows-desktop
flutter run -d windows
```

### Нет звука
- Убедитесь, что громкость не на 0%
- Проверьте, что дек имеет загруженный трек
- Нажмите ▶ (Play) под деком
