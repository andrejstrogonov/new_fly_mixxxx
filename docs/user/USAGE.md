Как пользоваться приложением

Краткое руководство по основным возможностям:
- Загрузка аудио и создание композиции
- Управление треками на микшере (громкость, баланс, эффекты)
- Экспорт композиции

Если вам нужно руководство по конкретной функции — откройте issue или загляните в файл USAGE.md для расширенного руководства (может быть добавлено позже).
