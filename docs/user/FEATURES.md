# Функции

Ключевые возможности:

## 🎵 Микширование и управление звуком
- **Двойной микшер** - одновременное воспроизведение из двух деков
- **Кроссфейдер** - плавное переключение между двумя треками
- **10-полосный эквалайзер** - точная настройка частот (60Hz - 40kHz)
- **Карусель EQ пресетов** - быстрое переключение между 9 жанрами музыки
- **BPM контроль** - управление темпом и скоростью воспроизведения
- **Master Volume** - управление общей громкостью

## 🎼 Инструменты для продюсеров
- **Анализ звукового оборудования** - детальный анализ АЧХ/ФЧХ оборудования
- **Диаграмма Боде** - визуализация частотной характеристики
- **Генерация композиции** - создание из 4 мелодий с помощью нейросети/API
- **Выбор API** - поддержка MCP-сервера и облачных сервисов

## 📁 Управление файлами
- **Загрузка треков** - поддержка MP3 и других форматов
- **Очереди** - создание очередей из 4 треков
- **Экспорт/импорт** - сохранение очередей и пресетов

## 🌍 Кроссплатформенность
- Windows (оптимизировано для desktop)
- Android (мобильное управление)
