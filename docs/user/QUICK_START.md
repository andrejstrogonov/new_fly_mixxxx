Быстрый старт (пользователь)

Запуск приложения (десктоп Windows):
1. Убедитесь, что у вас установлен Flutter и собран exe (или используйте встроённый установщик, если он есть).
2. В каталоге проекта выполните: `flutter run -d windows` — это запустит приложение для тестирования.

Примечание: для конечных пользователей обычно распространяется готовый установочный пакет — проверьте релизы проекта.
