# Что это такое?

Fly Mixxx — это профессиональное DJ-микшерное приложение для Windows и Android с поддержкой:

- **Аудио микширования**: Работа с несколькими аудио дорожками одновременно
- **Эквалайзера**: 10-полосный EQ с предустановками для разных жанров
- **Частотной характеристики**: Визуализация АЧХ, ФЧХ и диаграммы Боде
- **Анализа оборудования**: Определение параметров звукового оборудования
- **Генерации композиций**: AI-powered создание мелодий через нейросеть (API)

# Установка

## Windows

1. Скачайте `new_fly_mixxxx.exe` из релизов проекта
2. Запустите установщик (если это MSI) или просто запустите EXE
3. Приложение готово к использованию

## Android

1. Скачайте `app-release.apk` из релизов
2. Включите установку из неизвестных источников в настройках
3. Установите APK файл
4. Откройте приложение из меню приложений

# Базовое использование

## Загрузка аудио

1. Нажмите кнопку "Загрузить трек"
2. Выберите MP3 или WAV файл
3. Трек будет добавлен в очередь

## Микшер

1. **Громкость**: Используйте слайдер громкости для каждой дорожки
2. **Баланс**: Переместите звук между левым и правым каналами
3. **Эффекты**: Применяйте встроенные эффекты

## Эквалайзер

1. Выберите предустановку для жанра (Bass Boost, Treble Boost и т.д.)
2. Или настройте вручную каждую из 10 полос
3. Слушайте результат в реальном времени

## Анализ частотной характеристики

Откройте вкладку "Frequency Response" для просмотра:
- **АЧХ** (Амплитудная частотная характеристика)
- **ФЧХ** (Фазовая частотная характеристика)
- **Диаграмма Боде** (логарифмическая шкала)

# Решение проблем

## Нет звука

1. Проверьте громкость в Windows (правый нижний угол)
2. Убедитесь что микс не на 0%
3. Выберите правильное аудиоустройство в настройках

## Приложение тормозит

1. Закройте другие приложения
2. Уменьшите качество визуализации в настройках
3. Используйте более мощный компьютер для сложных задач

## Не распознаются MP3 файлы

Убедитесь что файл действительно MP3 (проверьте расширение файла).

# Форматы файлов

Поддерживаемые форматы:
- MP3
- WAV
- OGG
- FLAC

# Экспорт

Сохраняйте свои миксы в WAV формате:
1. Нажмите "Export"
2. Выберите папку сохранения
3. Укажите имя файла
4. Нажмите "Save"

Экспорт может занять время в зависимости от длины миха.
