# Поддержка

Если у вас возникли проблемы, создайте issue в репозитории с описанием: шаги для воспроизведения, ожидаемое поведение, фактическое поведение, окружение (OS, Flutter/Dart версии).

Контакты

- Issue tracker: https://github.com/your/repo/issues
- Email: support@example.com (замените на реальный)
