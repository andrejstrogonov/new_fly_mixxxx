# FAQ

Q: Приложение не запускается на Windows. Что делать?
A: Убедитесь, что установлен Flutter и Visual Studio с Desktop C++. Закройте все запущенные экземпляры приложения и повторите сборку.

Q: Плагины (file_picker) вызывают предупреждения?
A: Это предупреждение от Flutter о платформах плагина — как правило, можно игнорировать, но убедитесь, что используемая версия плагина совместима с вашей версией Flutter.

Q: Как использовать MCP-сервер для генерации?
A: Смотрите `USAGE_GUIDE.md` — там описаны способы подключения к API и локальному MCP-серверу.
