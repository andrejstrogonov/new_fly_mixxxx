# Руководство пользователя

## Основные разделы приложения

### 1. Загрузка треков
Используйте кнопку "📁 Load Track" для выбора MP3 файлов. Можно загружать треки как на Deck 1, так и на Deck 2.

### 2. Управление деками (Decks)
Каждый дек имеет:
- **Play/Pause** - воспроизведение/пауза
- **Stop** - остановка трека
- **Volume** - регулятор громкости
- **Progress bar** - прогресс воспроизведения

### 3. Эквалайзер (10-Band Equalizer)
10 вертикальных ползунков для настройки частот от 60Hz до 40kHz. Каждый диапазон можно отрегулировать в пределах -12dB до +12dB.

### 4. 🎪 Карусель EQ пресетов (NEW!)
**Что это?** Быстрое переключение между 9 предустановленными жанрами музыки.

**Как использовать:**
1. **Свайпание** - проведите влево/вправо по карточке для переключения жанров
2. **Клик на точки** - нажмите на одну из точек-индикаторов внизу
3. **Просмотр** - карусель показывает название, описание и статус активного жанра

**Доступные жанры:**
- 🎼 **Flat** - нейтральное звучание
- 🎺 **Tango** - подчеркнутый средний диапазон для вокала
- 🎷 **Jazz** - теплые басы и яркие верхи
- 🎻 **Folk Argentino** - земляное, теплое звучание
- 🎸 **Folk Russian** - яркое и четкое
- 💃 **Cross-step Waltz** - с акцентом на ритм
- 🔊 **Bass Boost** - усиленные низкие частоты
- ✨ **Treble Boost** - усиленные высокие частоты
- 🎤 **Vocal** - оптимизировано для вокала

**Преимущества:**
- Компактнее чем набор кнопок (экономит ~40% экрана)
- Красивые анимации при прокрутке
- Легче выбирать нужный жанр на сенсорном экране

### 5. Кроссфейдер (Crossfader)
Плавное переключение между двумя деками. Позиция регулятора определяет громкость каждого дека:
- Левое положение = слышно только Deck 1
- Центр = одинаковая громкость
- Правое положение = слышно только Deck 2

### 6. Частотная характеристика (Frequency Response)
Визуализирует эффект эквалайзера:
- **АЧХ (Амплитудно-частотная характеристика)** - график зависимости амплитуды от частоты
- **ФЧХ (Фазо-частотная характеристика)** - график фазовых сдвигов
- **Диаграмма Боде** - логарифмические графики АЧХ и ФЧХ

### 7. Анализ звукового оборудования
Детальный анализ характеристик вашего звукового устройства и его влияния на воспроизведение.

### 8. Генератор композиций
Создание миксов из 4 мелодий с использованием:
- Облачных API (OpenAI, Anthropic и др.)
- Локального MCP-сервера (если развернут у вас)
