# Руководство пользователя

Описание основных экранов и действий:

- Экран микшера (`mixer_screen`): загрузка треков, управление громкостью, эквалайзер.
- Frequency Response: просмотр АЧХ/ФЧХ и диаграммы Боде.
- Генератор композиций: создание очереди из 4 мелодий с выбором API/локального MCP-сервера.

Для подробностей см. разделы в приложении и `FEATURES.md`.
