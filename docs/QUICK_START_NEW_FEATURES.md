# Краткое руководство: Новые функции Fly Mixxx

## 🎵 Функция 1: Анализ звукового оборудования

### Что это?
Инструмент для диагностики и анализа вашего аудио-оборудования и системных ресурсов.

### Как использовать?

1. **Откройте раздел "Audio Device Analysis"**
   - Это нижняя часть главного окна приложения

2. **Нажмите кнопку "Scan"**
   - Приложение проанализирует доступное оборудование
   - Дождитесь завершения анализа

3. **Просмотрите результаты:**
   - **Обнаруженные устройства** (входные/выходные)
   - **Характеристики каждого устройства:**
     - Имя и тип
     - Количество каналов (обычно 2 для стерео)
     - Частота дискретизации (Sample Rate) в Hz
     - Разрядность звука (Bit Depth) в битах
     - Задержка (Latency) в миллисекундах
     - Статус и используемый драйвер

4. **Системная информация:**
   - Загруженность CPU (должна быть < 80% для комфортной работы)
   - Использование оперативной памяти
   - Размер буфера обработки звука

### Зачем это нужно?
- Проверить, правильно ли подключено оборудование
- Проверить параметры для оптимальной работы
- Контролировать нагрузку на систему
- Диагностировать проблемы со звуком

## 🤖 Функция 2: Генератор композиций AI

### Что это?
Инструмент для создания новых музыкальных композиций из 4 базовых мелодий, используя искусственный интеллект.

### Быстрый старт (5 минут)

#### Шаг 1️⃣: Загрузка мелодий
1. В разделе **"Track Loader"** (верхняя часть)
2. Нажмите **"Add Track"** или **"Add Folder"**
3. Выберите 4 аудиофайла (MP3, WAV, FLAC)
   - Они распределятся между двумя деками (по 2 в каждом)

#### Шаг 2️⃣: Выбор AI провайдера
1. Откройте раздел **"AI Composition Generator"**
2. В выпадающем меню **"Select AI Provider"** выберите:
   - **"Local MCP Server"** - для приватного использования (рекомендуется)
   - **"OpenAI GPT-4"** - для облачной обработки
   - Другие облачные сервисы (требуют API ключ)

#### Шаг 3️⃣: Конфигурация (если нужна)
- Если выбран облачный сервис:
  - Введите API ключ в поле **"API Key"**
  - Нажмите **"Configure API"**
  - Нажмите **"Test Connection"** для проверки

#### Шаг 4️⃣: Настройка параметров
1. Введите **название композиции** (например: "My Tango Mix")
2. Выберите тип **аранжировки:**
   - `blend` - плавное смешивание мелодий
   - `sequential` - одна за другой
   - `harmony` - гармоническое наложение
   - `rhythm` - ритмическое совмещение

#### Шаг 5️⃣: Генерация
1. Нажмите кнопку **"Generate Composition"**
2. Дождитесь завершения (обычно 30 сек - 5 минут)
3. Просмотрите результаты в разделе "Generation Result"

#### Шаг 6️⃣: Экспорт
1. Выберите формат экспорта:
   - **MIDI** - для редактирования в DAW (Ableton, FL Studio и т.д.)
   - **WAV** - готовый аудиофайл
2. Нажмите **"Export"**
3. Сохраните файл

### Что такое локальный MCP сервер?

**MCP (Model Context Protocol)** - это протокол для работы с моделями ИИ.

**Локальный MCP сервер** позволяет вам:
- ✅ Работать без интернета
- ✅ Не платить за API запросы
- ✅ Сохранять приватность данных
- ✅ Получить полный контроль

#### Как установить локальный MCP сервер?

**На Windows:**

1. Установите Node.js (если не установлен):
   - Скачайте с https://nodejs.org/
   - Установите последнюю версию LTS

2. Создайте папку для сервера:
   ```
   mkdir C:\mcp-music-server
   cd C:\mcp-music-server
   ```

3. Инициализируйте проект:
   ```
   npm init -y
   ```

4. Установите зависимости:
   ```
   npm install express cors body-parser
   ```

5. Создайте файл `server.js` со следующим содержимым:

   ```javascript
   const express = require('express');
   const cors = require('cors');
   const bodyParser = require('body-parser');

   const app = express();
   app.use(cors());
   app.use(bodyParser.json());

   // Проверка здоровья
   app.get('/health', (req, res) => {
     res.json({ status: 'healthy' });
   });

   // API для композиций
   app.post('/compose', (req, res) => {
     const { melodies, title, arrangement } = req.body;
     
     // Возвращаем успешный результат
     res.json({
       id: `comp_${Date.now()}`,
       title: title,
       arrangement: arrangement,
       success: true
     });
   });

   const PORT = 3000;
   app.listen(PORT, () => {
     console.log(`MCP сервер запущен на http://localhost:${PORT}`);
   });
   ```

6. Запустите сервер:
   ```
   node server.js
   ```

7. Оставьте окно консоли открытым

**Теперь вы можете использовать "Local MCP Server" в приложении!**

### Часто задаваемые вопросы

**Q: Сколько времени занимает генерация?**
- Локальный сервер: 10-30 секунд
- Облачные сервисы: 30 сек - 5 минут

**Q: Какие форматы поддерживаются?**
- Входные: MP3, WAV, FLAC, M4A, AAC
- Выходные: MIDI, WAV

**Q: Можно ли использовать более 4 мелодий?**
- Нет, система требует ровно 4 мелодии

**Q: Нужен ли интернет для локального сервера?**
- Нет, локальный сервер работает полностью оффлайн

**Q: Как получить API ключ для облачных сервисов?**
- OpenAI: https://platform.openai.com/api-keys
- Google: https://cloud.google.com/
- Mubert: https://mubert.com/

**Q: Что делать если тесты соединения не проходят?**
- Для локального сервера: убедитесь что он запущен на порту 3000
- Для облачных: проверьте интернет и API ключ

## 📊 Интеграция функций

Обе функции работают вместе для оптимальной работы:

1. **Анализ оборудования** помогает выбрать оптимальные параметры для сборки композиций
2. **Генератор композиций** использует данные о параметрах оборудования для оптимизации выходного звука
3. Вместе они обеспечивают полный контроль над процессом создания музыки

## 🚀 Советы по оптимизации

### Для лучшего качества звука:
1. Используйте Sample Rate 48kHz или выше
2. Используйте Bit Depth 24-bit или 32-bit
3. Следите чтобы CPU load был < 70%

### Для более быстрой генерации:
1. Используйте локальный MCP сервер
2. Уменьшите размер файлов мелодий
3. Используйте более простой тип аранжировки

### Для экономии ресурсов:
1. Закройте другие приложения
2. Увеличьте размер буфера в Audio Device Analysis
3. Используйте локальный сервер вместо облачных
