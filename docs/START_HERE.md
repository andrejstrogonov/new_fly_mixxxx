## 🎓 Что такое Fly Mixxx?

Это DJ-микшер для Windows и Android. Можно:
- Миксовать несколько аудиодорожек
- Использовать 10-полосный эквалайзер
- Смотреть частотные характеристики
- Анализировать оборудование
- Генерировать мелодии через AI

## ⚙️ Три способа запуска

### 1️⃣ Командная строка (самый простой)
```bash
flutter run -d windows          # Windows
flutter run -d android          # Android
```

### 2️⃣ VS Code (удобнее)
1. Откройте папку проекта
2. Нажмите **Ctrl+Shift+D**
3. Выберите конфигурацию
4. Нажмите **F5** (Play)

### 3️⃣ Android Studio (как привычно)
1. Откройте проект
2. Выберите устройство
3. Нажмите **Shift+F10** (Run)

[Все детали](RUN_APP.md)
