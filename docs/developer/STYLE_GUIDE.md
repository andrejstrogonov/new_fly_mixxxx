# Руководство по стилю (Dart/Flutter)

1. Форматирование
   - Используйте `dart format .` перед коммитом.
   - Следуйте `analysis_options.yaml` в корне проекта.

2. Именование
   - Классы: PascalCase
   - Переменные и методы: lowerCamelCase
   - Файлы: snake_case.dart

3. Виджеты
   - Разделяйте Stateful и Stateless; небольшие виджеты — в отдельные файлы.
   - Используйте `Provider` для управления состоянием.

4. PR
   - Описание изменений, шаги для проверки, связанные issue.

5. Безопасность
   - Не коммитьте секреты; используйте env vars или локальные конфиги.
