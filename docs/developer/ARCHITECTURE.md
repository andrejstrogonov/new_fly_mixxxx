Краткая архитектура проекта

Основные части:
- lib/main.dart — точка входа приложения
- lib/screens — экраны приложения (UI)
- lib/widgets — переиспользуемые виджеты
- lib/providers — state management (Provider)
- lib/models — модели данных
- windows/ — нативный код и сборка для Windows

Рекомендации:
- Сохранять логику вне UI, в провайдерах и моделях
- Писать тесты для критичных компонентов (unit/widget)
- Документировать публичные API и сложную бизнес-логику
