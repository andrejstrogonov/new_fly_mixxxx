Документация для разработчиков

Здесь собраны руководства для разработчиков и contributors: настройка окружения, архитектура, правила вклада и отладка.

Файлы:
- CONTRIBUTING.md — правила и процесс внесения изменений
- SETUP.md — как подготовить окружение для разработки и сборки
- ARCHITECTURE.md — краткое описание архитектуры приложения

Если нужно добавить другие документы — создайте их в этой папке.
