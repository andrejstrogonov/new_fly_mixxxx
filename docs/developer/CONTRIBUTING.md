CONTRIBUTING — вклад в проект

Краткие правила:
1. Форк/ветка: создавайте отдельную ветку для каждой фичи/фикса: feature/<краткое-описание>
2. Коммиты: небольшие, с информативными сообщениями (тип: краткое описание)
3. PR: добавьте описание цели, шаги для воспроизведения и тесты
4. Код-стайл: следуйте существующему стилю проекта (Dart/Flutter)
5. CI: если добавляете зависимости — удостоверьтесь, что сборка проходит локально и в CI

Контакт: используйте issues для обсуждения больших изменений.
