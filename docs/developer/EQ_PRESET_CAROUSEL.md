# EQ Preset Carousel Widget

## Описание
Новый компонент для управления EQ предустановками жанров музыки с использованием carousel для экономии пространства на экране.

## Особенности

### 1. Компактный дизайн
- Использует карусель (PageView) вместо сетки кнопок
- Экономит место на экране (вместо 2x5 сетки - только 1 видимая карточка)
- Уменьшает визуальный беспорядок

### 2. Анимированный переход
- Трехмерные эффекты при прокрутке
- Smooth масштабирование (scale от 1.0 до 0.7)
- Вращение по оси Y для 3D эффекта

### 3. Навигация
- Свайп слева направо для переключения жанров
- Точки-индикаторы внизу
- Клик на точку для прямого перехода
- Текущий выбранный жанр подсвечен

### 4. Информативность
- Название жанра
- Описание (автоматически сокращается)
- Статус "Active" для текущего жанра
- Визуальная подсветка активного preset

## Структура компонента

```dart
EQPresetCarouselWidget
├── Header
│   ├── Title: "EQ Presets (Genres)"
│   └── Current Preset Badge
├── Carousel (PageView)
│   └── Preset Cards
│       ├── Genre Name
│       ├── Description
│       └── Active Indicator
└── Navigation Dots
    └── Clickable indicators
```

## Использование

```dart
// В mixer_screen.dart
const EQPresetCarouselWidget(),
```

## Доступные жанры (Presets)

1. **Flat** - Нейтральная плоская характеристика
2. **Tango** - Улучшенный средний диапазон для вокала и струнных
3. **Jazz** - Теплые басы и яркие верхи
4. **Folk Argentino** - Теплое и земляное звучание
5. **Folk Russian** - Яркое и четкое звучание
6. **Cross-step Waltz** - Сбалансированное с акцентом на ритм
7. **Bass Boost** - Усиленные низкие частоты
8. **Treble Boost** - Усиленные высокие частоты
9. **Vocal** - Оптимизировано для ясности вокала

## Преимущества перед предыдущим PresetsWidget

| Параметр | PresetsWidget | EQPresetCarouselWidget |
|----------|---------------|------------------------|
| Размер | ~300px высоты | ~180px высоты |
| Видимые items | Все (9 кнопок) | 1 основная + 2 по бокам |
| Анимация | Нет | Трехмерные эффекты |
| Навигация | Нажатие кнопки | Свайп / клик точку |
| Информативность | Только название | Название + описание |
| Мобильность | Плохая | Хорошая (свайп) |

## Технические детали

### Зависимости
- `flutter/material.dart`
- `provider/provider.dart`

- `initState()` - инициализация PageController
- `build()` - основной UI
- `_buildPresetCard()` - карточка одного preset

### Особенности реализации
- Использует `PageView.builder` для эффективности

- Автоматическое применение preset при прокрутке
