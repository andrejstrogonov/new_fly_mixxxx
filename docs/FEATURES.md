# Новые функции Fly Mixxx

## 1. Анализ звукового оборудования (Audio Device Analysis)

### Описание
Функция анализирует доступное звуковое оборудование на компьютере и предоставляет детальную информацию о его характеристиках.

### Функциональность

#### Информация о устройствах:
- **Имя устройства**: наименование аудио-интерфейса
- **Тип**: входное (input), выходное (output) или двунаправленное устройство
- **Количество каналов**: количество аудио-каналов (обычно 2 для стерео)
- **Частота дискретизации (Sample Rate)**: частота в Гц (обычно 44.1kHz, 48kHz, 96kHz)
- **Разрядность (Bit Depth)**: глубина звука в битах (16, 24, 32)
- **Задержка (Latency)**: временная задержка обработки звука в миллисекундах
- **Драйвер**: используемый драйвер устройства
- **Статус**: состояние устройства (активно/неактивно)

#### Системная информация:
- **Загруженность CPU**: текущая загруженность процессора в %
- **Использование памяти**: текущее использование оперативной памяти в %
- **Размер буфера**: размер аудио-буфера в семплах
- **Стандартное входное устройство**: устройство по умолчанию для ввода
- **Стандартное выходное устройство**: устройство по умолчанию для вывода

### Использование

1. Откройте вкладку **"Audio Device Analysis"** в главном экране миксера
2. Нажмите кнопку **"Scan"** для анализа доступных устройств
3. Просмотрите результаты:
   - Список всех обнаруженных устройств
   - Системная информация и нагрузка на ресурсы
   - Текущее состояние устройств и их характеристики
4. Обновите анализ в любой момент, нажав кнопку "Scan" снова

### Технические детали

Провайдер: `AudioDeviceAnalyzer` (`lib/providers/audio_device_analyzer.dart`)

Модель данных:
- `AudioDevice`: информация об отдельном устройстве
- `AudioSystemInfo`: информация о системе в целом

Методы:
- `analyzeAudioDevices()`: асинхронная функция анализа устройств
- `getDeviceInfo()`: получение информации об устройстве

## 2. Генератор композиций с помощью нейросети (AI Composition Generator)

### Описание
Функция позволяет создавать музыкальные композиции из 4 базовых мелодий, используя различные API искусственного интеллекта, включая локально развёрнутый MCP-сервер.

### Поддерживаемые AI провайдеры

#### 1. **OpenAI GPT-4** (облачный)
- URL: `https://api.openai.com/v1`
- Требуется API ключ
- Использует GPT-4 для анализа и генерации музыкальных композиций

#### 2. **Google MusicLM** (облачный)
- URL: `https://music-lm.googleapis.com/v1`
- Требуется API ключ
- Специализирован на генерации музыки из текстовых описаний

#### 3. **Локальный MCP сервер** (локальный)
- URL: `http://localhost:3000` (по умолчанию)
- Не требует API ключа
- Развёрнут на компьютере пользователя
- Идеален для приватных инсталляций

#### 4. **OpenAI Jukebox** (облачный)
- URL: `https://jukebox.openai.com/api`
- Требуется API ключ
- Специализирован на музыкальной генерации

#### 5. **Mubert AI** (облачный)
- URL: `https://api.mubert.com/v1`
- Требуется API ключ
- Облачный сервис генерации музыки

### Использование

#### Шаг 1: Выбор AI провайдера
1. Откройте вкладку **"AI Composition Generator"**
2. В разделе **"Select AI Provider"** выберите нужный провайдер из выпадающего списка
3. Если выбран облачный провайдер, в поле **"API Key"** введите ваш ключ API
4. Для локального MCP сервера убедитесь, что сервер запущен на `http://localhost:3000`

#### Шаг 2: Конфигурация
1. Нажмите кнопку **"Configure API"** для сохранения API ключа
2. Нажмите **"Test Connection"** для проверки соединения с провайдером
3. Убедитесь, что статус показывает **"Connection successful"**

#### Шаг 3: Загрузка мелодий
1. Используя **Track Loader** вверху экрана, загрузите **ровно 4 аудиотрека**:
   - Через **"Add Track"** - добавить отдельный трек
   - Через **"Add Folder"** - добавить все аудиофайлы из папки
2. Убедитесь, что в каждой очереди (Deck 1 и Deck 2) находится по 2 трека

#### Шаг 4: Генерация композиции
1. Введите **название композиции** в поле "Composition Title"
2. Выберите **тип аранжировки** (arrangement):
   - **blend** - плавное смешивание мелодий
   - **sequential** - последовательное проигрывание
   - **harmony** - гармоническое наложение
   - **rhythm** - ритмическое совмещение
3. Нажмите кнопку **"Generate"**
4. Дождитесь завершения генерации (процесс может занять от 10 секунд до нескольких минут)

#### Шаг 5: Работа с результатом
После успешной генерации:
1. Просмотрите результаты в разделе "Generation Result"
2. Экспортируйте композицию в формате:
   - **MIDI** - для редактирования в DAW
   - **WAV** - готовый аудиофайл

### Параметры генерации

- **Composition Title**: название вашей композиции
- **Arrangement Type**: стиль аранжировки (blend/sequential/harmony/rhythm)
- **AI Provider**: выбранный провайдер искусственного интеллекта
- **API Key**: ключ доступа (для облачных сервисов)
- **Test Connection**: проверка соединения перед генерацией

### Процесс генерации

Генератор выполняет следующие шаги:

1. **Анализ мелодий** (20% прогресса)
   - Определение темпа (BPM) каждой мелодии
   - Анализ тональности
   - Определение мажорной/минорной тональности
   - Анализ доминирующих частот

2. **Отправка провайдеру** (20% прогресса)
   - Подготовка данных в формате JSON
   - Отправка на выбранный API

3. **Обработка** (40% прогресса)
   - Нейросеть анализирует и объединяет мелодии
   - Применяется выбранный тип аранжировки
   - Оптимизируется звук

4. **Финализация** (20% прогресса)
   - Применение эффектов
   - Нормализация громкости
   - Подготовка к экспорту

### Локальный MCP сервер

#### Установка и запуск

Если вы хотите использовать локальный MCP сервер без облачных сервисов:

```bash
# 1. Установите Node.js (если не установлен)
# 2. Создайте директорию для MCP сервера
mkdir mcp-music-server
cd mcp-music-server

# 3. Инициализируйте npm проект
npm init -y

# 4. Установите зависимости
npm install express cors body-parser

# 5. Создайте файл server.js
# (см. пример ниже)

# 6. Запустите сервер
node server.js
```

#### Пример MCP сервера (server.js)

```javascript
const express = require('express');
const cors = require('cors');
const bodyParser = require('body-parser');

const app = express();
app.use(cors());
app.use(bodyParser.json());

// Проверка здоровья сервера
app.get('/health', (req, res) => {
  res.json({ status: 'healthy' });
});

// Endpoint для генерации композиции
app.post('/compose', (req, res) => {
  const { melodies, title, arrangement, provider } = req.body;
  
  // Здесь реализуйте логику генерации
  // или вызова другого AI сервиса
  
  const result = {
    id: `comp_${Date.now()}`,
    title: title,
    arrangement: arrangement,
    mixingStrategy: 'adaptive',
    confidenceScore: 0.85,
    duration: melodies.reduce((sum, m) => sum + m.duration, 0),
  };
  
  res.json(result);
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`MCP Music Server listening on port ${PORT}`);
});
```

### Технические детали

Провайдер: `CompositionGeneratorProvider` (`lib/providers/composition_generator.dart`)

Модели данных:
- `MelodyInfo`: информация об отдельной мелодии
- `GeneratedComposition`: информация о созданной композиции
- `AIProviderConfig`: конфигурация AI провайдера

Методы:
- `selectProvider(id)`: выбор AI провайдера
- `configureApiKey(key)`: конфигурация API ключа
- `testConnection()`: проверка соединения
- `generateComposition(melodies, title, arrangement)`: генерация композиции
- `exportComposition(composition, format)`: экспорт результата

### Ограничения и требования

- **Количество мелодий**: ровно 4 трека (не более, не менее)
- **Размер файлов**: максимум 100 MB на трек для облачных сервисов
- **Форматы**: MP3, WAV, FLAC, M4A, AAC
- **Интернет**: требуется для облачных сервисов
- **API ключи**: получите у соответствующих провайдеров

### Решение проблем

#### "No provider selected"
- Убедитесь, что выбран провайдер из списка
- Проверьте, что провайдер правильно загружен

#### "API key cannot be empty"
- Введите API ключ для облачного сервиса
- Для локального сервера ключ не требуется

#### "Connection test failed"
- Проверьте интернет-соединение (для облачных сервисов)
- Убедитесь, что локальный MCP сервер запущен (для локального провайдера)
- Проверьте правильность URL сервера

#### "Generation timeout"
- Увеличьте timeout в настройках
- Проверьте пропускную способность интернета
- Попробуйте меньший размер файлов мелодий

## Функции в главном окне

### Верхняя часть - Track Loader
- **Add Track**: добавить отдельный аудиофайл в очередь
- **Add Folder**: добавить все аудиофайлы из папки в очередь (до 4 файлов)
- **Clear Queue**: очистить всю очередь

### Средняя часть - Декс управления (Deck Controls)
- Проигрывание/пауза
- Перемотка
- Управление громкостью
- Кроссфейдер между двумя деками

### Нижняя часть - Анализ и Генерация
- **Equalizer**: 10-полосный эквалайзер с предустановками
- **Frequency Response**: анализ частотной характеристики
- **Audio Device Analysis**: информация о звуковом оборудовании
- **AI Composition Generator**: генерация композиций из 4 мелодий

## Примеры использования

### Пример 1: Создание танго-композиции из 4 мелодий

1. Загрузите 4 аудиофайла:
   - Мелодия 1 (мелодия): `melody_1.wav`
   - Мелодия 2 (гармония 1): `melody_2.wav`
   - Мелодия 3 (гармония 2): `melody_3.wav`
   - Мелодия 4 (бас): `melody_4.wav`

2. Выберите провайдер: **"Locally Deployed MCP Server"**

3. Введите название: **"Tango Argentino - Composition"**

4. Выберите arrangement: **"harmony"**

5. Нажмите **"Generate"**

6. Экспортируйте результат как **"MIDI"** для редактирования

### Пример 2: Анализ оборудования перед миксованием

1. Нажмите **"Scan"** в разделе Audio Device Analysis
2. Просмотрите информацию о подключённых устройствах
3. Проверьте задержку (latency) - должна быть минимальной
4. Проверьте CPU load - должна быть ниже 80%
5. При необходимости измените буфер для оптимизации

## Для разработчиков

### Структура кода

```
lib/
├── providers/
│   ├── audio_device_analyzer.dart   # Анализ оборудования
│   ├── composition_generator.dart   # Генератор композиций
│   └── audio_provider.dart          # Основной провайдер аудио
├── models/
│   ├── audio_device_model.dart      # Модели для оборудования
│   └── composition_model.dart       # Модели для композиций
└── widgets/
    ├── audio_device_analysis_widget.dart      # UI анализа оборудования
    └── composition_generator_widget.dart      # UI генератора
```

### Расширение провайдеров

Чтобы добавить новый AI провайдер:

1. Добавьте конфигурацию в `CompositionGeneratorProvider._availableProviders`
2. Реализуйте метод `_generateYourProvider()` в `_callAIProvider()`
3. Обновите UI в `composition_generator_widget.dart`
