# 🎛️ ROTARY KNOBS VISUAL GUIDE

## Как выглядит новая крутилка

### ASCII Представление крутилки (75x75 px)

```
        ▲ (0°)
       ╱ ╲
     ╱     ╲
   ╱         ╲
  ║           ║
  ║           ║  ← Внешнее кольцо (серое)
  ║           ║
   ╲         ╱
    ╲   ⚫  ╱    ← Центральный кружок
     ╲ ╱╲╲╱
      ↓ ↓ ↓
      ▼ (180°)

Когда крутится:

     ▲ (0°)           ▲ (0°)           ▲ (0°)
    ╱ ╲              ╱ ╲              ╱ ╲
  ╱  🎛️ ╲          ╱ 🎛️  ╲          ╱ 🎛️  ╲
╱ 25%  ╲        ╱ 50%   ╲        ╱ 75%   ╲
║       ║      ║         ║      ║         ║
║       ║  →   ║    ⚫    ║  →   ║    ⚫    ║
║   ⚫   ║      ║         ║      ║         ║
 ╲     ╱        ╲         ╱        ╲     ╱
  ╲   ╱          ╲ 🎛️   ╱          ╲ 🎛️╱
   ╲ ╱            ╲   ╱            ╲ ╱
    ▼ (180°)       ▼ (180°)       ▼ (180°)

МИНИМУМ              СЕРЕДИНА           МАКСИМУМ
```

## ВИЗУАЛЬНЫЕ КОМПОНЕНТЫ КРУТИЛКИ

```
          ▲ Начало (0°)
         ╱ ╲
        ╱   ╲         ┌─ Внешний край
      ╱       ╲       │  (серый, полупрозрачный)
    ╱           ╲     │
   │             │ ───┼─ Фоновый круг
   │             │    │  (темный, 0xFF1a1a1a)
   │      ⚫     │    │
   │    ╱   ╲   │    │  Центральный кружок
   │   ╱     ╲  │    │  (фиолетовый)
    │ ╱       ╲ │   │
    │          ╲│   │
     ╲          ╱   │
      ╲        ╱    │
       ╲      ╱     │
        ╲    ╱      │
         ╲  ╱       │
          ╲╱        │
          ▼ Конец (180°)

ЦВЕТА:
─────────
Фон:              0xFF1a1a1a (почти черный)
Внешнее кольцо:   Colors.grey (50% прозрачность)
Активная дуга:    Colors.deepPurple (фиолетовая)
Стрелка:          Colors.deepPurple (фиолетовая)
Центр:            Colors.deepPurple (фиолетовая)

ДИАПАЗОН:
─────────
Начальный угол: -135° (верхний-левый)
Конечный угол:  +135° (нижний-левый)
Всего диапазон: 270°

При изменении значения от min к max, стрелка вращается от -135° к +135°
```

## ИНТЕРАКТИВНОСТЬ

### Как управлять крутилкой

```
Шаг 1: Коснись крутилки
      🎛️ 50%
    ↓ Палец здесь

Шаг 2: Перемещай палец вокруг крутилки (drag)
      ↗️ 🎛️ ↖️
      ↓   ↑   ↓
      ↙️ 🎛️ ↙️

     Результат: Значение изменяется гладко
                75% → 80% → 85% → 90%...
                
Шаг 3: Отпусти палец
      Value: 90% ✓

ОСОБЕННОСТИ:
- Плавное изменение (не "прыгает")
- Работает на любых сенсорных экранах
- 360° вращение (можно крутить полностью)
- Визуальная обратная связь (активная дуга)
```
